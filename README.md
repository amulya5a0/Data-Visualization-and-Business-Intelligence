# Data Visualization – Tableau, Power BI & Looker Studio

## Project Overview

This project focuses on exploring data visualization techniques and business intelligence tools to transform data into meaningful visual representations. Through hands-on practice with Tableau, Microsoft Power BI, and Looker Studio, I explored different chart types, interactive dashboards, filters, data storytelling, and calculations.

The objective was to understand how data visualization helps identify patterns, analyze trends, compare information, and communicate insights effectively for data-driven decision-making.

## Tools & Technologies Used

### 1. Tableau

**Overview:**

Tableau is a Business Intelligence (BI) and data visualization platform used to analyze data and create interactive visualizations and dashboards. It helps users explore datasets, identify trends, and communicate insights through graphical representations.

**Concepts Explored:**

- **Charts and Visualizations:** Created different visual representations to analyze and compare data.
- **Bar Charts:** Used to compare values across different categories.
- **Line Charts:** Used to identify trends and changes over time.
- **Treemaps:** Used to display hierarchical data and compare categories based on their relative sizes.
- **Filters:** Explored filtering options to focus on specific data points and categories.
- **Dashboards:** Combined multiple visualizations into a single interactive view.
- **Data Storytelling:** Explored how to organize visualizations to communicate patterns, trends, and meaningful insights effectively.

### 2. Microsoft Power BI

## Data Analysis & Visualization Concepts

### 1. Data Visualization

Data visualization is the graphical representation of information using charts, graphs, and dashboards. It helps simplify complex datasets and makes patterns, relationships, and trends easier to understand.

### 2. Data Storytelling

Data storytelling combines data, visualizations, and explanations to communicate meaningful insights. It helps transform raw information into a structured narrative that supports understanding and decision-making.

Key aspects:
- Identifying meaningful patterns and trends.
- Selecting appropriate visualizations.
- Highlighting important findings.
- Presenting insights in a clear and understandable manner.

### 3. Data Filtering

Data filtering involves selecting specific records or categories from a dataset based on defined conditions. It helps focus analysis on relevant information and makes visualizations easier to explore.

### 4. Dashboards

Dashboards combine multiple charts, graphs, and key metrics into a single interface. They provide an organized overview of information and help users monitor and compare different data points.

### 5. Aggregate Functions and Calculations

Explored basic calculations and aggregation concepts used in data analysis:

- **SUM:** Calculates the total of numerical values.
- **AVG (Average):** Calculates the mean of numerical values.
- **Aggregate Functions:** Summarize data to generate meaningful results.
- **Custom Calculations and Fields:** Create calculated values using expressions to support specific analytical requirements.
